## Objective

At the end, a synthetic ERA5-shaped NetCDF archive exists under
`tests/fixtures/`, is generated by a committed script, is small enough to commit,
and `conftest.py` exposes it as fixtures so that `LANLMJODataset` can be
constructed **with no CFS mount and no GPU**.

## Why this is a separate task

This is the load-bearing piece of the whole test suite. D2 and D3 both depend on
being able to build a dataset offline. If the fixtures are wrong-shaped, every
test built on them is testing a fiction — so this gets its own budget and its own
verification against `03_DOMAIN_PRIORS.md`.

## Why synthetic, not real

The template says fixtures should be real samples. Here they cannot be: a real
ERA5 file is ~100 MB, lives on a read-only allocation belonging to another group,
and CI has no mount for it. (`01_TARGET_STATE.md` §8)

The mitigation is that the generator is **committed and reviewable**, and its
docstring states exactly which real-data properties it reproduces and which it
deliberately does not. A synthetic fixture whose provenance is a script is more
trustworthy than a real one whose provenance is "someone copied it once".

## What you may assume

From `02_UPSTREAM_CONTRACT.md` §2, the directory layout the loader globs:

```text
<root>/Step00/ERA5.invariant/                       *_z.*.nc, *_lsm.*.nc
<root>/Step01/ERA5.remap_180x360MODIS_6hrInst/gopt/  var z
<root>/Step01/…/sphu/  q     <root>/Step01/…/tprt/  t
<root>/Step01/…/uWnd/  u     <root>/Step01/…/vWnd/  v
<root>/Step02/…/T2/    t2    <root>/Step02/…/U10/   u10
<root>/Step02/…/V10/   v10   <root>/Step02/…/PS/    ps
<root>/Step02/…/tcwv/  tcwv
<root>/Step03/…/meanTNLWFLX/  mtnlwrf
```

**Native variable names differ from Aurora names** — `msl` reads `ps`, `ttr`
reads `mtnlwrf`. Get this wrong and the loader finds nothing.

From `03_DOMAIN_PRIORS.md`: native grid 180×360; 13 pressure levels
`(50,100,150,200,250,300,400,500,600,700,850,925,1000)`; 4 timesteps/day;
`slt` comes from a **separate** `slt_data.nc` already at 0.25° and is truncated,
not upsampled.

Plausible value ranges are in `03_DOMAIN_PRIORS.md` §5 — use them, so a test
asserting "2t looks like a temperature" is meaningful.

## Steps

1. Write `scripts/make_test_fixtures.py`. It generates a synthetic archive into
   a target directory (default `tests/fixtures/synthetic_archive/`).

   Requirements:

   - **Reduced grid to keep size down.** Use 18×36 (a 10× coarsening in each
     direction) rather than 180×360, and **state in the docstring that the grid
     is reduced and which tests therefore cannot assert real shapes.** Full 13
     pressure levels — the level count matters for index probing, the horizontal
     resolution does not.
   - **Two years**, 1980 and 1981, so year-range filtering (Lesson 5) is
     testable. 1980 is a leap year, 1981 is not — that asymmetry is deliberate
     and it is what makes the sample-count arithmetic testable.
   - **Real `time` coordinates** at exact 6-hour spacing, since the v3 index is
     built from `time` coords, not filenames.
   - **File chunking that differs between variables** — e.g. `t2` one file per
     year, `q` one file per half-year. This reproduces the property that
     motivated the v3 per-variable index (`02_UPSTREAM_CONTRACT.md` §4.2) and
     without it D3 cannot test the thing that matters most.
   - **Values in physically plausible ranges** per `03_DOMAIN_PRIORS.md` §5,
     deterministic under a fixed seed. Smooth fields, not white noise — a
     lat-dependent gradient plus a small sinusoid is enough.
   - `slt_data.nc` generated separately at 720×1440 (or a proportionally reduced
     0.25°-equivalent), matching the asymmetry in the real code.
   - `float32`, `zlib` compression, and a `--report` flag printing total bytes.

   Also generate a **deliberately gapped** variant under
   `tests/fixtures/synthetic_archive_gapped/` with a fortnight of `tcwv` missing.
   D3 needs it to test that a gap removes samples rather than misaligning reads.

2. Generate and check the size. **Target under 5 MB total**; hard ceiling 20 MB.
   If you exceed it, coarsen the grid further or drop to 18 months rather than
   committing a large blob. State the final byte count.

3. Confirm `.gitignore` does not eat them. A2 should have added
   `!tests/fixtures/**` alongside the `*.nc` rule; if not, add it with a comment
   saying these are small synthetic files and pointing at this task. Verify with
   `git check-ignore -v tests/fixtures/synthetic_archive/...` on an actual
   generated file.

4. Write `tests/conftest.py` providing session-scoped fixtures:

   | Fixture | Yields |
   | --- | --- |
   | `synthetic_root` | `Path` to the synthetic archive |
   | `synthetic_root_gapped` | `Path` to the gapped variant |
   | `synthetic_slt` | `Path` to the synthetic `slt_data.nc` |
   | `synthetic_dataset` | a constructed `LANLMJODataset` over 1980 only |
   | `unified_config` | the resolved `baseline` config dict |
   | `baseline_fingerprint` | B1's `tests/fixtures/baseline/*.json` loaded as dicts |

   Set `HDF5_USE_FILE_LOCKING=FALSE` in `conftest.py` at import time, with a
   comment pointing at `02_UPSTREAM_CONTRACT.md` §4.5. E1 will set it in the
   package too; having it in both is correct, not redundant — tests must not
   depend on E1 having landed.

   Add a `pytest_collection_modifyitems` hook that **auto-skips** `needs_gpu`
   tests when `torch.cuda.is_available()` is false, with a clear skip reason. A
   developer on a laptop should get skips, not errors.

5. Write `tests/test_fixtures.py` — tests **of the fixtures themselves**, because
   an unverified fixture is worse than no fixture:

   - every expected directory and file exists
   - each variable file opens and contains its **native** variable name
   - `time` coords are exactly 6 hours apart with no duplicates
   - the two years have 1,464 and 1,460 timesteps respectively
   - variable file counts differ between `t2` and `q` (chunking asymmetry
     present)
   - the gapped variant really is missing `tcwv` timesteps, and the count of
     missing steps is asserted
   - every field's mean sits in the `03_DOMAIN_PRIORS.md` §5 range
   - total fixture size on disk is under the stated ceiling

6. Confirm `LANLMJODataset` constructs against the fixtures offline. This is the
   real acceptance test for this task:

   ```bash
   uv run pytest tests/test_fixtures.py -v
   uv run python -c "
   from aurora_mjo.dataset import LANLMJODataset
   ds = LANLMJODataset(start_year=1980, end_year=1980,
                       root_dir='tests/fixtures/synthetic_archive',
                       slt_path='tests/fixtures/slt_data_synthetic.nc')
   print('samples:', len(ds))
   b, s, a = ds[0]
   print('init time:', b.metadata.time[0])
   "
   ```

   **Expect 1,462 samples** for 1980 — same arithmetic as the real data, since
   the timeline is what matters, not the grid. If you get a different number,
   work out why before proceeding: either your `time` coords are wrong or you
   have found something about `_build_aligned_index` that `03_DOMAIN_PRIORS.md`
   §1 does not capture. Both are worth reporting.

   Note the loader upsamples statics to 720×1440 and the trainer upsamples the
   rest on GPU, so shapes coming out of a reduced-grid fixture will not match
   `03_DOMAIN_PRIORS.md` §2. **Say which shape assertions are therefore
   impossible on synthetic fixtures**, so D2 and D3 do not write tests that
   silently assert the wrong thing.

7. Remove the `pytest` exit-code-5 special case from `scripts/check.py` that A3
   added — `tests/` now exists and collects. Confirm the gate still passes.

## Out of scope

- Converting the existing smoke/verify scripts (D2).
- Writing regression tests for the seven lessons (D3).
- Any edit to `src/`. If `LANLMJODataset` cannot be constructed against
  synthetic data **without** a source change, stop and raise a question — that
  is a finding about testability, and it is E1/E2's territory, not a quick fix
  here.
- Committing any real ERA5 data. Not one file, not a subset.
- Touching `tests/fixtures/baseline/` or `postrefactor/`.
